SOURCE BEHAVIOR REVIEW
- Windows System.Media.SoundPlayer reads/plays PCM WAV data from Audio.
- The Scale method adjusts PCM16 samples for the voice-volume setting.
- A single worker and named mutex serialize playback; Stop waits for the worker.
- A local text protocol reports ready/playing/done/stopped/error states.
- A game-process-name check keeps the helper alive during map loading.
- File access is limited by application logic to the mod root/Runtime and WAV
  requests within the mod's Audio directory.
- The helper exits when its session is superseded or the game is gone and
  its heartbeat expires. It installs no startup task, service, or registry key.
- No network, download, microphone, credential, injection, anti-debug or
  privilege-elevation functionality appears in the reviewed C# source.
- The Lua launcher starts the included helper as a normal child application.
  It does not alter Windows security settings.
